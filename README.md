# RAG Assistant

An AI-powered Retrieval-Augmented Generation (RAG) assistant that will retrieve relevant information from documents and use it to generate context-aware answers.

## Project Status

Initial development environment setup completed.

## Technology Stack

- Python
- Git
- Visual Studio Code
- pytest
- Ruff

Additional technologies for document processing, embeddings, vector search, and language-model integration will be selected during implementation.

## Local Setup

1. Install the required Python version.
2. Create a virtual environment.
3. Activate the environment.
4. Install project dependencies when the dependency configuration is available.

## Run the Application

```powershell
python .\src\main.py
```

## Run Tests

```powershell
python -m pytest
```
